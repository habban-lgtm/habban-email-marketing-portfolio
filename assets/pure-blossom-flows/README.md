# Pure Blossom — Flow Overview

This folder contains visual portfolio evidence for the Pure Blossom Klaviyo client project.

## Included Flow Overview

The visual evidence covers the live lifecycle flows configured in Klaviyo:

- Welcome Flow
- Abandoned Cart
- Abandoned Checkout
- Customer Winback
- Sunset / Unengaged Subscriber Flow

## Client Privacy

**Performance results, conversion data, revenue figures, and customer-level information are intentionally not shown in the flow screenshot because of client confidentiality and privacy requirements.**

The screenshot is provided to demonstrate the **flow architecture, lifecycle strategy, automation structure, and implementation work** rather than disclose private client performance data.

> Client performance metrics can be discussed privately during the hiring process where appropriate.
